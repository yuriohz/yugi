# Chrome Web Store listing draft

## Name
WriteRight — AI Proofreader

## Short description
Catch spelling and grammar mistakes wherever you type, powered by your own OpenRouter API key.

## Detailed description
WriteRight helps you write clearly on WhatsApp Web and in editable fields across the web.

• Find spelling, grammar, and punctuation issues
• Review every suggestion before applying it
• Accept one correction or all corrections
• Choose your preferred OpenRouter model
• Keep your API key in local Chrome storage
• Pause proofreading whenever you want

WriteRight uses your configured OpenRouter account. API usage may incur charges from your provider. AI suggestions can be inaccurate, so review changes before accepting them.

## Category
Productivity

## Permission justification

**Storage:** Saves the user's API configuration, language, and enabled preference locally.

**Host access (`<all_urls>`):** Required because the user expects proofreading in writing fields across websites, including WhatsApp Web. It also enables requests to a user-configured API endpoint. WriteRight activates only around supported editable fields and excludes password inputs.
